# Product Rules

- Report private saat `SUBMITTED`, `UNDER_REVIEW`, `NEEDS_INFO`, atau `REJECTED`.
- Hanya moderator/admin dapat melakukan moderasi.
- Moderator/admin tidak dapat memeriksa kirimannya sendiri.
- Satu laporan dapat menyertakan sampai delapan nomor/akun terkait.
- Data akun tambahan baru ditautkan ke profil publik setelah laporan diterbitkan admin.
- Reporter ber-role `USER` tetap anonim di publik. Nama akun hanya boleh diatribusikan pada laporan `PUBLISHED` jika pengunggah ber-role `ADMIN`, `MODERATOR`, atau `VERIFIED_MIDDLEMAN`.
- Badge uploader menjelaskan role akun pengunggah, bukan jaminan kebenaran laporan; status `PUBLISHED` tetap berasal dari proses review terpisah.
- Phone, bank account, dan e-wallet yang terikat langsung ke laporan `PUBLISHED` ditampilkan penuh. Data nonpublik, identifier korban/pelapor, dan identifier yang tidak terikat langsung ke laporan published tetap dimasking.
- Dashboard Akun Saya hanya menampilkan kontribusi milik actor yang sedang login. Laporan nonpublik, email, dan catatan moderasi tidak boleh tersedia melalui endpoint publik atau kepada user lain.
- Public profile bersifat opt-in melalui username unik. Response publik tidak boleh memuat email, data autentikasi, bukti privat, laporan nonpublik, atau catatan moderasi.
- Username publik hanya dapat diganti sekali setiap tujuh hari. Pembuatan username pertama langsung memulai periode cooldown; bio tetap dapat diedit selama cooldown.
- Testi milik user hanya tampil di public profile setelah `APPROVED`. Scam report milik user biasa tetap anonim dan tidak tampil di public profile; atribusi report hanya berlaku untuk role publik tepercaya.
- Community post dapat dibaca publik, tetapi hanya user login dengan username publik yang dapat menulis. Isi post dibatasi 3–1.000 karakter dan write rate dibatasi satu post per menit.
- Community post bukan laporan terverifikasi, tidak memengaruhi risk label, dan tidak boleh menjadi jalur publikasi tuduhan baru tanpa bukti. Penulis dapat menghapus post sendiri; moderator/admin dapat melakukan soft delete.
- User login hanya dapat melaporkan post user lain satu kali per post. Alasan dan penjelasan laporan bersifat privat dan tidak boleh dibuka kepada penulis post atau publik.
- Beberapa report untuk community post yang sama digabung menjadi satu keputusan moderasi. Moderator/admin wajib menulis alasan, tidak boleh meninjau post miliknya sendiri, dan keputusan harus masuk audit log.
- Keputusan `DISMISS` mempertahankan post dan menutup semua report pending; keputusan `REMOVE` melakukan soft delete post sekaligus menutup semua report pending.
- Tidak ada hasil tidak berarti aman.
- Raw evidence tidak dipublikasikan otomatis.
- Pelapor dapat menyertakan link posting bukti HTTP(S), misalnya posting komunitas Facebook, sebagai alternatif atau pelengkap upload file.
- Link bukti hanya tampil setelah laporan `PUBLISHED`. Gambar upload hanya tampil jika admin memilihnya sebagai bukti publik setelah memastikan isinya aman; PDF dan file yang tidak disetujui tetap privat.
- Form memprioritaskan rekening dan e-wallet, lalu telepon dan username. Data Riot memisahkan username utama dan nickname/Riot ID opsional; pengguna dianjurkan menyertakan identifier kuat lain karena nickname dapat berubah.
- Setiap platform hanya muncul sekali pada pemilih jenis data. Rekening dan e-wallet memuat provider, nomor, serta nama pemilik opsional; Riot memuat username dan nickname opsional; Facebook memuat nama dan link profil opsional.
- Saran bank/e-wallet memakai combobox internal yang mengikuti visual Valrify, tetap searchable, dan tetap menerima provider di luar daftar.
- Validasi form ditampilkan dalam bahasa Indonesia di dalam form, bukan melalui popup validasi bawaan browser.
- Tanggal kejadian publik ditampilkan dengan format Indonesia (contoh: `12 Agustus 2026`) dan status publik memakai label `PUBLISHED`.
- Kartu hasil search dan baris scam report harus jelas dapat diklik melalui CTA permanen, hover/focus state, dan target sentuh yang luas.
- Heading serta susunan kartu harus memiliki skala mobile tersendiri; identifier panjang wajib membungkus tanpa memaksa horizontal overflow.
- Halaman selain homepage menyediakan link kembali kontekstual khusus mobile; link memakai tujuan internal yang pasti, bukan browser history yang dapat membawa pengguna keluar situs.
- Nama seller menjadi judul profil utama. Nama asli, nama Facebook, dan nama pemilik rekening disimpan sebagai nama terkait/alias yang terstruktur.
- Pencarian nama dan username mendukung potongan minimal dua karakter. Rekening, e-wallet, dan telepon tetap wajib cocok tepat setelah normalisasi agar pencarian angka pendek tidak menjadi enumerasi data.
- Nama atau kemiripan teks tidak pernah menggabungkan profil secara otomatis; auto-link hanya memakai identifier kuat yang cocok tepat.
- Fuzzy name tidak pernah memicu merge otomatis.
- Label risiko rule-based dan selalu memiliki penjelasan.
- Konfirmasi transaksi berhasil wajib login, email terverifikasi, dan moderasi sebelum publik.
- Satu user hanya dapat mengirim satu konfirmasi per entity dan tanggal transaksi.
- Konfirmasi positif tidak menghapus laporan atau menurunkan label risiko secara otomatis.
- Komentar community hanya dapat dibuat oleh user login yang memiliki username publik, berisi 2–500 karakter, dan dibatasi satu komentar setiap 30 detik.
- Komentar hanya boleh menempel pada post community yang masih `PUBLISHED`. Komentar `REMOVED` tidak dihitung atau dikirim oleh endpoint publik.
- Penulis hanya dapat menghapus komentarnya sendiri. Penghapusan komentar bersifat soft delete dan menyelesaikan report pending pada komentar tersebut.
- Satu user hanya dapat melaporkan komentar yang sama sekali. User tidak dapat melaporkan komentar miliknya sendiri.
- Moderator/admin tidak dapat memoderasi komentar miliknya sendiri atau report komentar yang dikirimnya sendiri.
- Komentar dan jumlah komentar tidak memengaruhi risk label, status scam report, atau reputasi entity secara otomatis.
- Reply komentar disimpan sebagai relasi ke komentar yang dibalas, tetapi seluruh komentar tetap tampil dalam satu level visual dan urutan waktu agar thread mobile tidak semakin menjorok.
- Target reply wajib merupakan komentar `PUBLISHED` pada post yang sama. Jika komentar target dihapus, reply tetap dapat dibaca tanpa membuka kembali isi target.
- User login dapat memberi satu like per komentar dan dapat membatalkannya. Like tidak memiliki bobot pada risk label, status moderasi, atau reputasi entity.
- Dislike tidak disediakan untuk mengurangi brigading pada diskusi yang berkaitan dengan tuduhan dan reputasi.
- User login dapat memberi satu like per post community dan dapat membatalkannya; jumlah like bersifat publik.
- Feed `Lagi Ramai` hanya memberi bobot engagement pada post 30 hari terakhir. Skor v1 adalah dua poin per like dan tiga poin per komentar `PUBLISHED`, lalu waktu post menjadi tie-breaker.
- Like post maupun posisi di feed ramai tidak memengaruhi risk label, status scam report, keputusan moderasi, atau reputasi entity.
- Feed yang masih tertutup hanya menampilkan maksimal satu top reply. Top reply dipilih dari komentar `PUBLISHED` dengan like terbanyak; waktu terbaru menjadi tie-breaker.
- Hitungan komentar tidak diulang pada action like post. Jumlah balasan hanya tampil pada CTA pembuka thread.
- Notifikasi v1 hanya dikirim kepada pemilik post atau komentar untuk like dan balasan Community. Aksi pada konten sendiri tidak menghasilkan notifikasi.
- Membatalkan like menghapus notifikasi like terkait. Menghapus atau memoderasi konten turut membersihkan notifikasi yang menuju konten tersebut.
- Inbox notifikasi bersifat privat, dibatasi 50 aktivitas terbaru, serta menyediakan tandai satu atau semua sebagai dibaca. Notifikasi tidak memengaruhi risk label maupun reputasi entity.
- Setiap post Community `PUBLISHED` memiliki halaman detail publik yang dapat dibagikan. Post `REMOVED` wajib menghasilkan 404 dan tidak boleh tetap dapat dibaca melalui URL lama.
- Deep link notifikasi komentar membuka halaman post detail dengan thread terbuka dan target komentar tersorot. Detail post tetap mengikuti aturan login, username, report, delete, dan like yang sama seperti feed.
- Community Search terpisah dari pencarian data penipu. Query 2–80 karakter mencari isi post `PUBLISHED` secara case-insensitive serta nama/username anggota yang memiliki profil publik.
- Hasil Community Search tidak boleh memuat post `REMOVED`, email, data autentikasi, report privat, bukti, atau identitas pelapor. Pencarian post dan anggota ditampilkan pada tab terpisah.
